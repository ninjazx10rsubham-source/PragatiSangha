# প্রগতি সংঘ শ্রী শ্রী শ্যামা পূজা - ক্লাউড পোর্টাল (সংস্করণ ২.০) 🪔

একটি আধুনিক, দ্রুত ও স্বয়ংসম্পূর্ণ ক্লাব ও পূজা ম্যানেজমেন্ট ওয়েব পোর্টাল — তৈরি করা হয়েছে **React 18 + Vite + Tailwind CSS + Supabase Realtime Database** দিয়ে।

---

## 🌟 নতুন যুক্ত হওয়া সুবিধাসমূহ (New Features)

1. **ডিজিটাল চাঁদার রসিদ (Digital Chanda Receipt Generator):**
   - স্বয়ংক্রিয় রসিদ নম্বর (যেমন: `PS-2026-0001`)।
   - প্রগতি সংঘের সিলমোহর ও আনুষ্ঠানিক বিন্যাস সহ প্রিন্টযোগ্য স্লিপ।
   - বাংলায় টাকায় পরিমাণ (কথায় ও সংখ্যায়, যেমন: `পাঁচশত টাকা মাত্র`)।
   
2. **সরাসরি হোয়াটসঅ্যাপে রসিদ পাঠানো (WhatsApp Share):**
   - এক ক্লিকে সদস্যের নম্বরে আনুষ্ঠানিক রসিদ ও কৃতজ্ঞতাপত্র পাঠানো।

3. **বাকি চাঁদার হোয়াটসঅ্যাপ রিমাইন্ডার (Due Payment Reminder):**
   - যাদের চাঁদা বাকি বা আংশিক জমা, তাঁদের ভদ্রভাবে হোয়াটসঅ্যাপে স্মরণ করিয়ে দেওয়ার বাটন।

4. **ভোগ ও প্রসাদ কুপন বিতরণ ট্র্যাকার (Bhog Coupon Distribution):**
   - বাড়ি অনুযায়ী ভোগের কুপন বরাদ্দ ও বিতরণ চেকলিস্ট।
   - সদস্য তালিকা থেকে এক ক্লিকে সমস্ত বাড়ি অটো-ইম্পোর্ট করার সুবিধা।

5. **ব্যানার, তোরণ ও বিজ্ঞাপন স্পনসরশিপ (Sponsorship Management):**
   - তোরণ, গেট ব্যানার, স্মরণিকা বিজ্ঞাপনদাতার হিসাব।
   - প্রতিশ্রুত টাকা বনাম প্রাপ্ত টাকা ও বাকি হিসাব।

6. **এক্সেল এক্সপোর্ট (Excel .xlsx Export):**
   - সদস্য তালিকা, খরচের ভাউচার, বাজারের ফর্দ, স্পনসর ও ভোগ কুপন তালিকা এক ক্লিকে ডাউনলোড।

7. **সাধারণ নাগরিকদের পাবলিক ভিউ (Public Portal):**
   - পাসওয়ার্ড ছাড়া পাড়ার যে কেউ পূজার সময়সূচি, পুষ্পাঞ্জলি ও ভোগের সময় দেখতে পারবেন।
   - নিজের নাম লিখে রসিদ ভেরিফাই করতে পারবেন।

8. **Supabase ক্লাউড ও অফলাইন ডুয়েল মোড (Cloud & Offline Sync):**
   - Supabase যুক্ত করলে একাধিক ফোনে রিয়েলটাইমে একযোগে কাজ করা যাবে।
   - ইন্টারনেট বা Supabase ছাড়া চললেও ব্রাউজারের লোকাল স্টোরেজে সম্পূর্ণ অফলাইনে সুরক্ষিত থাকবে।

## 🚀 কীভাবে চালু করবেন (How to Run)

টার্মিনাল বা কমান্ড প্রম্পটে প্রজেক্ট ফোল্ডারে গিয়ে রান করুন:

```bash
# ডেভেলপমেন্ট সার্ভার চালু করতে:
npm run dev
```

ব্রাউজারে সরাসরি খুলে যাবে: `http://localhost:3000`

## 🗄️ Supabase ডাটাবেস সেটআপ নির্দেশিকা (Supabase Setup)

1. [Supabase](https://supabase.com)-এ একটি ফ্রি প্রজেক্ট তৈরি করুন।
2. বাম পাশের মেনু থেকে **SQL Editor**-এ যান।
3. প্রজেক্টের `supabase/schema.sql` ফাইলের পুরো কোড কপি করে পেস্ট করে **Run** করুন।
4. **Project Settings -> API** থেকে:
   - `Project URL`
   - `anon / public API key`
5. অ্যাপ্লিকেশন চালু করে উপরে ডানে **"ক্লাউড কানেক্ট করুন"** বাটনে ক্লিক করে URL ও Key পেস্ট করে **"সেভ ও কানেক্ট করুন"** চাপুন!
6. এরপর **"লোকাল ডেটা আপলোড করুন"** চাপলেই পূর্বের সমস্ত ডেটা ক্লাউডে চলে যাবে।
